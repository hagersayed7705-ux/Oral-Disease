🚀 **Oral Diseases Classification Using Deep Learning**

I'm excited to share my **Oral Diseases Image Classification** project, where I applied Deep Learning techniques to build an AI-based image classification system.

🦷 **Project Overview:**
The goal of this project is to classify oral images into six categories:
- Calculus
- Caries
- Gingivitis
- Mouth Ulcer
- Tooth Discoloration
- Hypodontia

🛠️ **Technologies & Techniques:**
- Python
- TensorFlow & Keras
- Convolutional Neural Networks (CNN)
- Transfer Learning using MobileNetV2
- Image Preprocessing & Data Augmentation
- Class Weighting to help address class imbalance
- Gradio for building an interactive web interface

💡 **Key Learning Outcomes:**
- Building and training deep learning models for image classification
- Applying transfer learning to improve model performance
- Evaluating model predictions and addressing class imbalance
- Deploying a trained model through an interactive interface

This project helped me strengthen my practical skills in Deep Learning, Computer Vision, and model deployment.
